# 口径与决定变更记录（骏大祭 / matsuri）

> **本文件是「为什么这么定」的单一事实源**：口径裁定、用语选择、数值口径修正、
> 与旧实现 / 资料的分歧，全部按日期记在这里。
>
> 分工：术语与官方译名 → [`glossary.md`](glossary.md)；机制公式与流程 → [`mechanism.md`](mechanism.md)；
> 阶段推进与待决事项 → [`plan/scenario_dev_plan.md`](plan/scenario_dev_plan.md)；
> 数值占位 → [`plan/stubs.md`](plan/stubs.md)。本文件**不是代码变更史**，代码改动看 `git log`。

## 写入纪律

1. **只追加，不改历史行**：新决定追加一行；被取代的旧结论在原「决定」列内标注
   「（已被 YYYY-MM-DD 修正：…）」，不删行、不改写原意。
2. **日期 = 拍板日期**，不是实现日期；同一天多轮按时间先后追加。
3. **`基线影响` 列必须写影响面**：无影响写「无（……）」，有位移给数字（分数 / PT / 卡数）。
4. **同时同步**：影响机制表述的改 `mechanism.md`；影响术语的改 `glossary.md`；
   位移基线的重录 `baselines/*.json` 并改 `baselines/README.md`。
