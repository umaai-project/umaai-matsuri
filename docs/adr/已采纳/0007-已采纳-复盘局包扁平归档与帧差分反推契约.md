# ADR-0007: 复盘局包扁平归档与帧差分反推契约

- **状态**：已采纳
- **日期**：2026-11-14
- **关联**：`matsuri-cli`、`matsuri-tools`、[ARCHITECTURE.md](../../../ARCHITECTURE.md)、[todo.md](../../todo.md)

## 背景（Context）

真机复盘需要归档整局回合帧与终局信息。若引入独立元文件目录、`records/` 子目录或扩充玩家操作序列（记录改选教诲/转成/学技能过程），会增加插件与复盘工具的跨端同步复杂度，且过程操作本身不是复盘关注重点。

## 决策（Decision）

1. **扁平局包与内嵌摘要**：`game{id}.zip` 直接扁平存放在 `PluginData/SendGameStatusPlugin/`（不再建 `records/`），仅装帧文件与 `finalScore.json`；局级摘要（起止回合、缺帧、`loads` 时间线等）内嵌进 `finalScore.json` 的 `review` 子对象，不新建 `meta.json`。
2. **生效结果由帧 diff 反推**：「效果可核、过程不评」——教诲分配、転成与学技能不扩写 `actions`，统一由逐帧 `adviceId` / `fusionId` / `skillPt` 差分反推。
3. **单次终局 AI 标记与收窄边界**：`matsuri-cli online` 仅在 T77 终局帧到达时写入一次 `game{id}_ai-decision.json` 标记在场；复盘工具不做「AI 估分 vs 实际终局」对照与轨迹一致性校验，且直接报错拒绝旧 `illEffects` 帧或无 `review` 段老包。

## 影响（Consequences）

- 插件归档与复盘解析契约极简，打包清理仅删本局回合帧与 `ai-decision`，不干扰 `FileChannel` 白名单。
- 放弃对旧格式老包的向后兼容，后续复盘工具只面向新版归档包演进。
