# Hint → 技能分折算公式（研究记录）

> 状态：**研究/待定，当前实际公式未改**。本文件只记录两类候选公式与 2026-11-20 的真机验证结论，避免过程数据散落。

## 1. 现用公式（线性，保留）

模拟口径（`total_pt` 中间量 → 评分）：

```
total_pt  = floor(skill_pt + 6.5 × total_hints)        // hint_pt_rate = 6.5
score_pt  = total_pt × 1.88 × 切者/小切因子            // pt_score_rate = 1.88
```

展开后等价于：

```
score_pt = 1.88 × skill_pt + 12.22 × total_hints
```

（另有「固有技能分 510」一项，按 5 星写死。）

## 2. 候选公式（折扣脱钩，未采用）

目标：`skill_pt` 直接折算成分，不经过 `total_pt`；hint 以「平均打折比例」表达。

```
score_pt = skill_pt × base / ((1 − d(H)) × (1 − qie))
d(H)     = min(d_max, k × H / N)
```

- `base` ≈ 1.34–1.46（1.2 = 讲义 217 型裸性价比 × 1.12 = 最优选技增益）
- `d_max` = 0.4（讲义 5 档折扣：10/20/30/35/40%，原价基础上优惠、上下位独立）
- `qie` = 0.04（小切）/ 0.10（切者），作为价格分母
- 结论：固定 `d` 饱和时只能拟合 6334（小切局），9 个无切旧局会低估 5–25%；需要更多真机数据才能标定 `k` / `N`。

## 3. 验证数据（2026-11-20）

- 真机 6330 / 6334 / 6335：**全部小切**（`isXiaoQie=true`，技能价格 −4%）
- 旧 9 局（7053 / 7054 / 7062 / 7064 / 7065 / 7067 / 7072 / 7074 / 7084）：**全部无切者/小切**
- 关键口径：`finalScore.skillPt` 是**剩余**技能点，累计获得 = `skillPt + skillPtSpent`
- 用累计口径 + 旧公式估技能分：11 局「分/PT」收敛到 **2.37–2.48（均值 ≈2.43）**
- 帧内 `ptScoreRate = 2`（游戏内口径）；模拟的 1.88 是含 hint 折算的等效系数

## 4. 后续

- 暂不改实际公式；继续收集真机信息：技能分字段（或已购技能列表 + 价格）、切者/小切状态、卡组技能池规模。
- 数据齐备后再决定是否把「折扣脱钩」落地（改 `umasim/uma.rs` 的 `total_pt` / pt 项 + 常量 + 重录基线）。
