# Hint → 技能分折算公式（研究记录）

> 状态：**2026-11-23 复核：线性公式保留、固定分 510 已去掉；折扣脱钩方案被真机数据否定**。
> 本文件记录公式候选与真机验证结论，避免过程数据散落。

## 1. 现用公式（保留，510 已去）

模拟口径（`total_pt` 中间量 → 评分）：

```
total_pt  = floor(skill_pt + 6.5 × total_hints)        // hint_pt_rate = 6.5
score_pt  = total_pt × 1.88 × 切者/小切因子            // pt_score_rate = 1.88
```

- `skill_score` 固定分：2026-11-23 由 **510 改为 0**（`umasim` `Uma::new`）。真机 skillplan 对账：去 510 后 6341/6342 误差 −25 / −276（0.03% / 0.35%），含 510 时 +535 / +786；6334 反推也是 +510。
- 展开后等价于 `score_pt = 1.88 × skill_pt + 12.22 × total_hints`（× 切因子）。
- 算分仍按 `total_pt` 折算；终端显示已把「技能点」与「Hint 等级」分开，不再显示折算后 PT。

## 2. 候选公式（折扣脱钩，已否）

原目标：`skill_pt` 直接折算成分、hint 用「平均打折比例」表达：

```
score_pt = skill_pt × base / ((1 − d(H)) × (1 − qie))
d(H)     = min(d_max, k × H / N)
```

2026-11-23 用 6341/6342 skillplan 最优方案反推：

| 量 | 文档假设 | 6341 实测 | 6342 实测 |
|---|---|---|---|
| 每点原价技能分 base | 1.34–1.46 | 1.917 | 1.868 |
| 平均折扣 d（Σcost/Σbase） | d_max 0.4 | 0.208 | 0.198 |

- `base` 偏差约 40%；`d` 受组内前置价（cost>base 行）污染，且仅凭总 H 不可预测；
- 线性 `1.88 × 切因子 × PT` 对最优方案已准，折扣脱钩不再作为候选。

## 3. 真机价格公式（确认）

```
cost = floor(baseCost × (100 − hint折扣% − 切折扣%) / 100)
hint L1–L5 折扣 = 10 / 20 / 30 / 35 / 40%
小切 −4%，切者 −10%
```

6341 单价行 58/58、6342 62/62 全部命中；`cost > baseCost` 的行是组内前置合计价，不参与单价校验。

## 4. 验证数据

- 真机 6341 / 6342（小切、pt_favor_rate = 5.0）：skillplan 最优总分 77299 / 79313，五维分 54214 / 55828，累计 PT 11820 / 12153，购买技能分/PT 1.896 / 1.876；
- 模拟真机卡组：手写档 pt=5.0 时 6341 卡组 H 420.4 / PT 11859；搜索档 N=2048 时 H 420.4 / 412.4；真机 H 393 / 363（模拟偏高 +27 / +49）；
- hint_efficiency 扫描（0.92 → 0.84）：H 420.4 → 395.7、412.4 → 387.0；PT/score 变化小，score 偏高主因是五维（搜索档速/智触顶），压 H 不解决；
- 旧 6334：真实技能分 23308 = 1.88 × (剩余 skillPt + 6.5×H)，M0 额外 +510 即误差来源。
