## 1. 回合与阶段

> 口径：本文 turn 一律 **0 基**（`turn ∈ [0, 77]`）；`master.mdb` / 游戏内显示为 1 基，必要时在括号内保留原始值。

- 回合范围：`turn ∈ [0, 77]`（全 78 回合）；Senior 10 月後半最终结算在 `turn 67`。
- 三次剧本结算 / 進捗発表会：`turn 23 / 47 / 67`，门槛全演目 Lv `3 / 5 / 6`
  （`single_mode_15_schedule`；`need_act_num = 5`）。
- 合宿窗口：`turn 12–15 / 36–39 / 60–63`（0 基；Junior 即有夏合宿）。
- **合宿规则**（官方帮助）：合宿中**每回合都能进行演目稽古**；合宿中**演目 Lv 不上升**；
  合宿结束后**全演目 Lv +1**；合宿中无体力回复事件（「不回体」仅指没有合宿内回体事件）。
- **合宿延长**（user 实测 2026-10-26）：基础 4 回合；若合宿窗口内出现目标比赛或强制休息，
  合宿按回合顺延，直到该年累计 **4 个非比赛合宿回合**。比赛回合与强制休息回合不计入这 4 个。
  - 例：樱花进王顺延到 10 月前半（0 基 turn 66）；凯斯奇迹 9 月前半比赛、9 月后半比赛触发强制休息，
    10 月前半仍有顺延合宿回合。
  - ❓延长合宿的演目 Lv +1 结算点（8 月后半合宿结束事件 vs 全部顺延结束）待确认。
- **支援卡事件抑制**（user 实测 2026-10-26）：正常 4 回合合宿期间不触发支援卡事件
  （含连续事件，第一年同样）；8 月后半合宿结束事件（turn 15 / 39 / 63）之后，
  延长合宿回合是否触发支援卡连续事件 ❓待测。AI 端当前未记录合宿结束事件，对结算影响小。
- 本番后：剧情结束，但仍可攒 gauge / 执行演目稽古直到 `turn 77`（URA 收尾）。
- 阶段机（内部强类型，对外 `StageId`）：当前 S1 阶段机为 `Begin → Train → End`；真实阶段需按
  合宿 / 伝受 / 発表会 / 本番 / URA 收尾拆分。❓精确阶段顺序待收口。

## 2. 资源与账本

- 剧本资源：**5 条演目ゲージ**（对应 5 训练）+ **5 个演目 Lv**。
- gauge 上限 **5**（真机 `NeedActGauge = 5`）；不随回合自然减少。
- 入账（memo 2026-10-27）：对应演目担当**每参与 1 人 +1**，友情训练 **+2**；
  **目标比赛 +4**；休息 / 外出 / 非目标比赛 **+1**。
  分配顺序：**演目 Lv 与 gauge 最低者优先**。
  ❓「彩圈 / 友情」是按参与人数全部 +2，还是仅彩人物，待真机。
- 消费：gauge 满后对应训练变演目稽古；执行后该演目 `Lv +1`、gauge 清零；
  **稽古失败时 gauge 保留、Lv 不升**。
- 可延期：亮起后不必立即执行、不会过期；多个演目同时亮起可任选其一，其他不消失。
- 跨回合状态存局面字段，不存阶段枚举。
- Senior 期各演目再 **+1 名担当**（memo；待真机）。
- 剧本链接角色（固定演目担当）按**固定演目**判定 gauge / 教え / 稽古登场，不按支援卡类型。
- 真机 `ActInfoArray` 每个元素：`ActType / ActGauge / Level / NeedActGauge / ActTrainingState /
  AdviceId / FriendOutingGainActLevel`；`ActType` 是主键（1–5），不是 `command_id`。

**计算公式（memo 2026-10-27，上段）**

- 基础能力：`floor(下段 × (1 + 友情合计) × (1 + 训练效果合计) × (1 + 获得量合计)) - 下段`；
  **演目稽古再 +10**。
- SP：`floor(下段 × (1 + 友情合计) × (1 + 训练效果合计 + SP训练效果)) - 下段`。
- 友情合计（仅友情训练）：駿大祭 buff、協力教え、稽古的演目 Lv 效果、得意率転成（稽古）。
- 训练效果合计：助力（非友情时）、助力支撑、両道（稽古）、不屈（稽古）。
- 获得量合计：主属性：特化、絆（稽古）、絆転成（稽古）；副属性：両道（SP 除外）。
- 教え效果按「教え绑定的演目担当**参与人数**」叠加；演目 Lv 取绑定演目，与训练种类无关；
  絆 +3 不叠加。
- ❓下段公式 memo 仍 TODO；演目稽古基础值随时期 / 训练 Lv 变化（见 §3.2 注）。

### 3.3 教え（教え）加成

- 教え作用于「演目担当」（含编成外神駒），不是全体人头；羁绊教え只对编成支援卡生效。
- 效果按「教え绑定的演目担当参与人数」叠加（例：助力担当 2 人则助力效果 2 倍）；
  演目 Lv 取**教え绑定的演目**，与训练种类无关；絆 +3 不叠加。
- 転成效果同样按参与担当人数叠加。
- 实现口径（memo 调查项）：特化的基础上限也作用于 SP 上限；稽古 +10 不吃非得意加成；
  絆 +3 吃愛嬌補正且单独加算；転成的「灵感 +1」= Hint Lv+1；全 Hint 发动包含 guest；
  研鑽发生率按担当人数加算、上限 100%、仅成功时触发。
- 逐级数值见 [`plan/intake.md`](plan/intake.md) §3.4；下表只记口径：

| 教え | 作用 | 关键口径 |
|---|---|---|
| 絆の教え | 絆 +3（固定、不叠加）+ 演目稽古主基础 % | `effect_type 16 / 13` |
| 得意率の教え | 得意率 +10…50 | `effect_type 4` |
| ヒントの教え | 灵感率 +30…80% | `effect_type 2` |
| 助力の教え | 非友情训练效果 +20…40% + 「助力の支え」 | `condition_type 3` |
| 体力の教え | 演目稽古体力消耗 -1…15% | `effect_type 3`（负值） |
| 特化の教え | 主基础 +5…25% + 基础上限 +5…25 | `13 / 206` |
| 研鑽の教え | 「追加の稽古」发生率 20…80% | `effect_type 8` |
| 協力の教え | 友情 +1…10% + 演目担当卡额外随机 1 处 | `202 / 18` |
| 不屈の教え | 体力阈值下失败率 -100%；Lv8+ 追加演目稽古效果 | `205（cond 2）/ 203` |
| 両道の教え | 副基础 +1…25% + 演目稽古效果 +1…15% | `21 / 203` |

## 4. 比赛与赛程

- 赛程：各马娘固有目标赛事 + URA 决赛收尾；Senior 10 月後半本番为剧本最终结算，不是育成结束。
- 合宿期间有目标比赛则合宿延长：**不产生额外回合**，把后续正常回合改标为合宿回合；
  规则是**每年保证 4 个非比赛合宿回合**，比赛 / 强制休息回合不计入，按回合顺延。
- 合宿产出实测约 **2.59×** 普通回合（964 份报文：普通 n=63 中位 +56 / 合宿 n=12 中位 +145）；
  这是合宿整体产出比（含休息与稽古），**不能当纯稽古倍率**。❓用途待定（训练员估值）。
- ❓延长段的支援卡事件与演目 Lv +1 结算点见 §1 / §5.3。
- 比赛倍率 / PT 折算：memo 给出赛后奖励（目标赛：五维 +5、SP +72？；目标外 GI：1 项 +10、SP +45；

  ❓目标赛 SP+72 与是否还有剧本专属倍率待真机。

  每个初始教え仅一次；组合确定后不可改；追加 5 种不可作材料。

## 7. 随机轴与可复现

- 局面流 / 事件流：由 `BaseGame` 持有，每回合按 `(master, turn)` 派生。
- 策略流：本局面自持，动作结算与剧本机制随机从它取；`set_rule_master` 与回合边界重置。
- 决策流：只给 `Trainer`，不影响结算随机。
- `fork_for_rollout`：克隆 + 注入 rollout 主种子；任何不由传入 rng 驱动的流必须在这里重置。
