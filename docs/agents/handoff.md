# 会话交接（Handoff Skill）

当上下文过长或需要由新会话 / 新 Agent 接续当前工作时，按本规范生成交接文档并**写入 `docs/handoff.md`**（按需创建；本仓约定使用仓内固定路径，不写入系统临时目录）。

## 执行规范

1. **浓缩状态，面向接续**：总结当前目标、已完成事项、当前阻塞点/未决决策以及下一步明确动作，使新 Agent 无需翻阅长历史即可直接开工。
2. **只引用、不重复**：已在其他文档（Spec、Plan、ADR、`GLOSSARY.md`、Git commit/diff）记录的内容，直接给出相对路径或标识链接，不整段复制。
3. **敏感信息脱敏**：交接文档会落入工作区文件，务必剔除 API Key、密码、Token 或个人隐私信息。
4. **按后续焦点裁剪**：若用户指明了下一阶段的工作重心，围绕该焦点组织交接内容并过滤无关细节。
