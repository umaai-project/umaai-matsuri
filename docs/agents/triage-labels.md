# 分诊标签（Triage Labels）

工程技能内部使用五个标准分诊角色。本文件将这五个标准角色映射为本仓库 Issue 追踪器中实际使用的中文标签名。

| 技能中的标准角色 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待分诊` | 维护者尚未评估该 Issue |
| `needs-info` | `待补充信息` | 等待报告者补充更多信息 |
| `ready-for-agent` | `Agent就绪` | 需求已明确，可交由后台 Agent 自动执行 |
| `ready-for-human` | `需人工处理` | 需要由人类开发者实现或决策 |
| `wontfix` | `不予处理` | 暂不处理或拒绝修改 |

当技能提及某个角色（例如“添加 Agent 就绪的分诊标签”）时，应使用上表“本仓库实际标签”列对应的标签字符串。

如需调整实际标签名，直接修改上表“本仓库实际标签”列即可。
