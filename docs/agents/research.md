description: "基于高可信度一手资料调研问题，并将结论整理为仓库中的 Markdown 文档。适合需要查阅文档、收集 API 事实或交由后台 Agent 调研的场景。"
---

启动一个**后台代理（background agent）**来执行调研，以便主会话在它阅读资料期间继续推进工作。为其分配全新的上下文窗口。

它的职责如下：

1. 对照**一手资料**（官方文档、源码、规范文档、第一方 API）核查问题，而不是依赖二手转述文章。每一条结论都必须溯源到拥有该事实的原始出处。
2. 将调研发现整理为单个 Markdown 文档，并为每一条结论标注来源引用。
3. 将文档保存在仓库已有的同类笔记目录中；遵循现有目录约定，若尚无约定则放在合理位置并明确说明存放路径。
