# 口径速查（matsuri）

## 1. 三个评分量，不可混

| 量 | 出处 | 量级 | 含义 |
|---|---|---|---|
| `score` | `brief.md` / `facts.json` | 万级 | **当前局面评分**（五维查表分 + PT + 技能分），不是期望 |
| `t_n` | `eval` 的 `EvalReport.t_n` | 八万级 | 从该点搜索到终局的**期望终局分** |
| `regret` | `eval` 的 `regret` | 百级 | 该点「最优 − 实际」的**决策差** |

同一回合两帧的 `score` 差（如 +1499）通常是**训练收益**，不是期望分抬升，也不是「教诲台阶」。

## 2. 命中判定

```
abs(regret) <= ci95  → 命中（噪声内，不展开、不写「失误」）
abs(regret) >  ci95  → 未命中（显著，才分析第几选、损失、五维/PT 取舍）
其余                  → 不可判（实际动作不在搜索候选 / 强制比赛 fallback / 多事件）
```

`--swap` 的 `Δ = 替代 − 实际`，同样按配对 CI 判命中。

## 3. 决策面与 seq

同一回合可能有多个决策面（帧）：

| 帧 | 面 |
|---|---|
| `source=event`（有 `storyId`） | 事件选项（**暂不比对**，见 §9） |
| `source=command`（`playing_state=1`） | 训练 / 比赛 |
| `source=special` 且 `playing_state=51` | 教诲分配 |

`eval` 单点在多面时必须 `--seq`（不给会报错并列出面名）；`--all` 逐面各算一点。
`whatif` 自动 **Advice 优先、其次 Train**，事件面不支持。

## 4. 检查项（门禁）

| 项 | 判据 | 取数 |
|---|---|---|
| B1 | 進捗発表会 / 本番未达门槛 | 结算前帧 `act_level` 自判（T23/47/67） |
| B4 | 合宿延长期回合 | `camp_extended`（info） |
| B6 | 体力 < 32 且训练无失败风险 | `failure_rate` + 下一帧 `vital`（只用训练前帧） |
| B7 | 干劲掉落 3 回合未恢复 | `motivation` 相邻下降 + 休息动作 |
| C3 | 训练失败（期望非零、五维零增长） | `derive.training[].failed` |
| C4 | 关键资源（吾妻出行 5 段 / 助力支撑） | 末帧 `out_used` / `assist_support_left` |

## 5. 剧本专属判据 (1)–(6)

1. **演目**：节点与卡位（只判结算，不判卡位；根位无卡是结构性）；
2. **出行**：只两条 warn，解锁时点不作判据；
3. **swings**：只做分解 + 阴跌段陈述，不做属性 gap / 超预期；
4. **继承**：只出实际值 + 对照 400/次标准，不做分位与 verdict；
5. **追加稽古**：以事件 `400015106` 为准，位置 = `kensan_act`；
6. **切者 / 小切 / 盾**：切者=随机好运、小切=局外口径不算运气、盾用「计数−事件对齐」。

## 6. 选择偏差（B2/B3/C1/C2）

统一判据：**实际 vs 同局面重算最优**，不依赖「当时建议」。
`eval` 的 `regret` + 逐 rollout 配对 CI（CRN 下比独立近似少假阴性）；跨零=同等优解。
教诲实际排列不在搜索候选（120 剪到 16）时 `regret` 不可判——用 `whatif` 强制该动作对照。

## 7. whatif 判读

- 固定手写训练员；基线 = 历史实际动作（反推失败才降级策略默认，报告标 `actual_source`）；
- 判读阈值：动作频率 `SE≈√(p(1−p)/K)`（K=100 时 ≈5pt），两比例差 **>10pt** 才算行为变化；
  均值差按 `SE=σ/√K`（K=100 时体力≈1.5、五维属性≈15、评分≈150），**>2SE** 才值得说；
- `--horizon 0` 跑满终局，另给 K 组终局分均值；
- 维度：动作分布、体力、干劲、五维属性、五维分、演目 Lv、技能点、PT、评分、五维分维。

## 8. 继承

`brief` 只给数字（如「T30 270」），**趋势判断由本 skill 做**：内部标准 306/次（`tuning.inherit_expect`），
低于 / 高于由模型判断后再说，标准值与差值都不写进叙事。

## 8.1 五维值的两种口径

`brief` / `whatif` 已统一输出**显示值**（真实值超 1200 的部分减半）；帧与 `view` 传的是真实值。
拿到数值时按来源判断：工具产物（brief/whatif/digest）一律直接用，不要再减半；自己读帧原始值时才需要换算。

## 9. 回合边界

- 强制比赛 / 本番 / URA 决赛：候选只有 1 个，`eval` 不可判、`whatif` 直接拒绝；
- 事件回合：`eval` 与 `whatif` 均不处理（选项比对波动大，2026-11-17 起停用）；
- 教诲窗口：帧里有 `special + ps=51` 才可用；缺失是采集侧问题，不是工具坏。

## 10. 档位口径（内置，输出不暴露）

评价表随游戏数据，终局分落表即档位。本版本的**内部判定线**：

| 内部口径 | 阈值 |
|---|---|
| 好局 | LG20 = 88,500 |
| 非常优秀 | LF = 91,400 |

**输出规则**：两条线只用于内部判断，叙事里不出现分数阈值。
过线时给一句正面表述（如「本局完成度很好」）；**未过线则不提交判定**，只讲事实与改进点。
档位名（如 LG4）可以直接引用——那是游戏自带评价，不是本 skill 的标准。
