# 马娘 / 赛程相关

- **赛程**：目标赛回合来自马娘自身赛程（帧 `raceHistory` 是「已比赛回合」含自选赛与输赢与否，不是「只记跑赢」）。
- **自选赛（E7）**：区间与要求场数来自引擎静态表 `free_races`；未打满只给 info，不判失败（真机输赢不可判）。
- **继承**：单次约 400 点（模拟口径），真机常达不到；只做「实际值 vs 标准」对照，不下 verdict。
- **URA 期**：T72–77，73/75/77 固定决赛；全稽古。
- **合宿**：窗口内全稽古；结算 T15/39/63 全演目 Lv+1；延长期回合单独列出（B4 info）。
- **友人出行**：5 段各 +1「当前最低演目 Lv」，上限 10；解锁是羁绊概率判定，不作判据。
- **馬娘专属**：依赖具体马娘赛程 / 固有 / 对手的判断，由模型层按机制读，工具不出结论。
