# wisdom_build 双智版参数与卡位定档（2026-11-17）

> 起因：外部报告（双智版参数全集）给出 lab GA 冠军 39 旋钮 + 双智配卡建议。本仓按「换卡与换参分开」做 2×2 配对验证后落库。
> 数据：手写档 5000 局/格，seed 87000（初筛）与 91000（留出确认）；配对差分按同种子逐局对齐，CI 取 95%。
> **本页数值为引擎修复（P0-1 种子派生 / P0-3 事件状态位 / P0-4 固有 20）之后的重测结果**；修复前的旧数值作废。
> 落库位置：`data/matsuri_config.toml` `[decks.wisdom_build]`（参数）、`benchmark/decks/wisdom_build.csv`（卡位）。

## 1. 起点差异（外部报告 vs 本仓）

报告起点 `w2_final` 与仓库原 `[decks.wisdom_build]` 逐位一致，仅 3 处不同：`pt_favor_rate` 2.2/1.799、
`weights.friendship` 8.0/3.35、`weights.hint` 20.0/5.78 —— 即 lab 是在本仓档上手工改成「偏 PT 起点」再搜。
冠军 r2 相对 r1 仅 +40~70 分，取 r1。报告只给 4–5 位有效数字，落库值是近似还原（±1% 量级）。

## 4. 口径提醒

本批模拟条件 `qie=none / shield=0 / uma=105902` 下好局线 88,500 不可达（P99 ≈ 85k），
「好局率」恒 0，故上界判据用 P95 / P99 与 ≥83k、≥84k 占比；要按 LG20 / LF 口径评须换真机条件。

## 5. 搜索档补测（`[search].pt_favor_rate`）

新增 `[search].pt_favor_rate`（`Option<f64>`，缺省 = 与手写档同口径）：只改搜索排序与搜索侧期望分换算，
手写训练员（剪枝 / fallback / rollout 教师）不受影响；`bench root` / `probe_fail` 同口径取该值。

修复前测得（N=128、200 局/格、seed 30,000,000）：默认 ptf 下 爱慕 82,656/PT 12,068、青春 82,111；ptf 5.0 下
81,101/12,476 与 80,480/12,482 → **ptf 5.0 对默认 −1,555.5 分 / +408.7 PT（3.81 分/PT）**，与 lab 报告同梯度
（−1,556 / +391）几乎重合；卡位结论在搜索档同向。

> 该段数值来自引擎修复前，**待重测**（搜索档 4 格约 32 min）。结论方向（ptf 换 PT 的效率、卡位同向）不受引擎修复影响。
