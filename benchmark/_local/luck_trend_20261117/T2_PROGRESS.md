## 3. T2 下陷：已排除的假设

| 假设 | 判据 | 结论 |
| --- | --- | --- |
| 搜索预算/噪声造成的假象 | N=512 / 2048 / 8192 各 6 局：下陷 −166 / −202 / −31，未随 N 消失（8192 档样本仅 6 局） | 排除（弱证据，末档样本不足） |
| UCB 权重随候选数稀释 | base 逐回合候选数 t0–t5 恒为 7.00，t6 才升到 7.07、t13 到 8.63 —— T2 处没有变化 | 排除 |
| 教诲分配"搜索 vs 手写"口径不一致 | 关掉教诲搜索（`[search] advice=false`）同 seeds 重跑 30 局：t0/t1 行逐位相同，T1→T2 下陷**仍存在且更大**（E −80.3±22.0、baseline −103.5±28.0，对照 −42.6±23.3 / −58.1±28.8） | 排除 |
| 旧分布污染 T2 的候选生成 / 剪枝 / 结算 | 代码实读：候选生成与 `assignment_value` 只读 slots/fused/person.act，不读 `base.distribution`；唯一读分布的 `participant_advice` 在下一个 Distribute 重算后才调用；rollout 自行跑到 Distribute | 排除 |
| `begin_tail` 被双跑 | `Begin + AssignAdvice` 的根动作收尾只重掷追加稽古；`End` 分支只处理 window 2/4 | 排除 |
| 未获得教诲时返回乐观默认值 | `advice_effect_of` 未 acquired 时返回零效果 | 排除 |
| T2 有额外规则随机 | T2 无 701，`roll_kensan` 直接返回；随机事件与 T1 同型 | 排除 |

## 4. 剩余可疑方向（未验证）

advice-off 实验把"教诲决策"这一层剥掉了，下陷反而更大，说明下陷的底座是 T2 这个决策点本身：

1. **NPC / 友人加入**（T2 Begin 的 `append_begin_friend_event`）导致的状态或候选池构成变化。候选数量不变（7.00），但**构成是否变化尚未验证**（`bench root` 只打印数量，不打印动作标签）。
2. **T2 决策点特有的估值偏差**：整池同幅下移、下一回合同幅回升，形态更像"该点定价偏低"，而不是状态真的更差（若是真实状态劣化，T3 应继承而不会一次性回升）。
3. 尚无解释的是：T0/T1 的 rollout 也会经过内部的 T2，若 T2 状态真的劣化，E(0)/E(1) 应同样体现；因此"水平下陷"这条线索更偏向口径/定价而非状态。

## 5. 续接方案（供拍板，未执行）

1. **状态快照探针**（推荐先做）：t=0..3 逐回合 dump 状态摘要 —— persons 的 (act/可用/加入回合)、每演目担当人数、acts.level、vital/干劲/fatigue、advice slots+fused、以及**全部候选动作标签**；对比 T1↔T2 的实际差异，确认候选构成是否换人。
2. 若状态无异常：怀疑"T2 这个决策点"的定价口径，用 `use_ucb=false`（会话目录 `ai_config.toml` 覆盖层）等权重复核 baseline，区分"加权口径"与"状态劣化"。
3. 若构成变了：直接在候选池层面拆分 —— 用 `bench root --turn 1/2` 打印动作标签，逐动作比 T1/T2 的均值，判定是"新动作拉低均值"还是"全体下移"。
4. 反向验证：把 T2 的分配固定为恒等分配（action index 0）跑 30 局，与现状对比（advice-off 已排除决策层，此项仅作交叉确认）。
