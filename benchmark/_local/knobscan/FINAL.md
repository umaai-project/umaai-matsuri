# 耐 / 根机制旋钮扫描结果（固定融合 ga-r2 #2）

## 执行概要

- 基准 = 教诲预设落地 + 五维系数结论后的当前生产档；只扫 stamina / guts。
- 16 旋钮 × 2 档 + 联合基座，坐标下降 2 轮；只累积正向增益的档。
- 12 批 / 795,000 局 / 跑测墙钟 626s（10.4 分钟）/ 278 个变体。
- 初筛 110000 块 2500 局 `--correct none`；复核 120000 块 5000 局 `--correct holm` + 影子同向。

## 结论

- 初筛最优 Δ = **−285.6 ±102.0**（`gu__rf_j_all`）。
- 独立块复核通过 **0 / 6** 组；6 组主卡组 Δ 全部**显著为负**
  （−298 ~ −392，p_adj 0.0000，影子卡组同向 −285 ~ −400）。

### 结论：两套 build 的旋钮配置保持继承 default

粗网格（0 / ×2）、细网格（相对当前 0.6/0.8/1.2/1.5×）、分组联合
（全组合 / 仅某组 / 留一）共 **278 个变体，没有任何一个优于当前配置**；
独立块进一步确认改旋钮只会更差。ga-r2 冠军档的这套训练员参数在 stamina / guts 上已是局部最优。

**残余失分是构成性的，不是旋钮能补的**：阶段 0 诊断显示
stamina 速度分项 −4374（comp 只有 1 张速卡，默认档 2 张）、
guts 耐力分项 −3163（comp 0 张耐卡）。教诲预设已各自补回 +834 / +579，
五维系数对 wisdom 补回 +631 但对这两套无效；继续调训练员旋钮只会破坏已调好的决策链。

要进一步缩小差距只有三条路：① 放开 comp 做构成搜索（方案 §2.1 明确另开一轮）；
② 扫 fusion（会改变 801 落位与教诲价值矩阵，之后 advice / 系数都要重扫）；
③ 接受这两套是不同流派，不以追平 speed 默认档为目标。
