# 灵感等级与 PT 估分对照

基于 `umaai-matsuri@a639a3c6`、`umaai-next@ae3cab19`。本实验不改模拟器、线上决策或默认系数。候选换分函数仅接收累计灵感等级 `H` 与未花费 PT `P`；不追踪技能，不给训练灵感计入金技或进化技能收益。

## 现状与候选

- 现版（无切者）：`trunc(floor(P + 6.5H) × 1.88)`，保留 Rust `f32` 与取整顺序。模拟初始 `H=21`。搜索的 `pt_favor_rate` 是策略权重，不参与此次评分校准。有既得技能分时，另计既得分，不能把含 `skillPtSpent` 回加的 `Uma.skill_pt` 当作 `P`。
- `rateH`：`r₀ P [1 + aH/(H+h₀)]`。累计灵感提高平均分/PT，但同一 H 的每级灵感收益与 P 成正比。
- `scoreHP`：`r₀ [P + (kH)(λP)/(kH+λP)]`。`kH` 是可产生优惠的规模，`λP` 限制预算可兑现的优惠；任一为零则优惠为零。新增灵感折分用 `scoreHP(H+ΔH,P) − scoreHP(H,P)`，不是把总折扣重复计入。`scoreHP/P` 是平均分/PT；多给 1 PT 的分差是边际价值，两者不相等。
- `7.5%` 是无加成的灵感基础概率，只在生成基线机会时抽样。条件已触发的 Hint 和累计 H 不再乘 `7.5%`；本实验不拟合触发机制。

## 复跑

CI 使用 Node.js 24 和生成的合成夹具，覆盖公式边界、CSV 三种子留出、配对标签导入和参数恢复，无需下载数据。复跑下方真实白技价格实验时，另提供本地 SO 导出。

```sh
node --test scripts/hint_pt_model.test.cjs
node scripts/hint_pt_model.cjs --test
node scripts/hint_pt_model.cjs --csv /path/to/skill-grade-pt-so-3.29.8.csv
node scripts/hint_pt_model.cjs --csv /path/to/skill-grade-pt-so-3.29.8.csv 20261121
node scripts/hint_pt_model.cjs --csv /path/to/skill-grade-pt-so-3.29.8.csv 20261122
node scripts/hint_pt_model.cjs --labels /path/to/paired-labels.json
```

CSV 列为 `skill_id,skill_name,rarity,group_id,group_rate,base_grade,base_pt`。使用已核验的 SO 3.29.8 导出，SHA-256 `a9617ea4ec8ac11de284b8ec7d2e8bf1a75671bfa9fe0b3cff84e9597cc5ca94`，不入仓。选取 455 项有正价格和基础分的白技（每组只取 `group_rate=1`），价格逐项向下取整，Hint Lv0–5 折扣为 `0/10/20/30/35/40%`。只评价基础分，不混入适性加权、切者、金技、升级或已买技能。

每个种子抽出六个互不重叠的白技池，各 64–84 项。每池 12 个模拟折扣状态，每状态测四种预算，共 288 对照行。七项初始 Lv3；60% 技能进入抽签池，其余机会数、目标、等级与预算也都是实验设定，不是真机频数。离线参照用 0/1 背包求给定预算内的最高白技分；新增 Hint 等级（+1/+3/+5）独立于基线折扣抽样，取同一状态下三个目标的平均分差，另测 `+8/16/32 PT`。这一步只生成标签，候选计算不读取技能池。每次整个白技池做留出，拟合只用其余五池；总分、Hint 分差与 PT 分差的平方误差分别用训练集均方尺度归一化。

## 留出结果

默认种子 `20261120`，`H=21–448`，`P=3205–10113`。各项单位均为评价分。

| 模型 | 总分 MAE | 新增 Hint 分差 MAE | 新增 PT 分差 MAE | 选错平均损失 |
| --- | ---: | ---: | ---: | ---: |
| 现版 `1.88 × (P+6.5H)` | 3346.656 | 19.384 | 20.319 | 2.750 |
| 固定 `1.88P` | 1480.844 | 26.167 | 20.341 | 11.869 |
| 拟合固定费率 | 1494.289 | 26.167 | 15.024 | 11.869 |
| `rateH` | 1597.371 | 14.675 | 15.343 | 2.524 |
| `scoreHP` | **868.786** | **12.988** | **14.971** | **2.091** |

| 种子 | Hint 分差 MAE：现版 → `scoreHP` | 选错平均损失：现版 → `scoreHP` | `scoreHP` 赢过现版的池数（损失） |
| --- | ---: | ---: | ---: |
| `20261120` | 19.384 → 12.988 | 2.750 → 2.091 | 3 / 6 |
| `20261121` | 22.546 → 15.012 | 6.480 → 2.813 | 6 / 6 |
| `20261122` | 21.932 → 12.654 | 4.500 → 2.773 | 5 / 6 |

「选错平均损失」是已发生的额外 Hint 与额外 PT 二选一时，参照最优分减候选选中项的参照分；不是整局搜索收益。三种子用同一份技能表，重复抽样不是独立真机局。`scoreHP` 的 Hint 分差误差在三次实验的每个留出池都低于现版，但选错损失并非每池都改善。

主种子全样本拟合 `r₀=1.3141941891, k=12, λ=2/3`，`λ` 达到预设搜索上界，另两次对应 `λ=0.5`。在 `H=383,P=9037`，主种子模型预测 `15302.64` 分，平均 `1.6933 分/PT`，边际 `+1 PT → +1.4783 分`，`+3 Hint Lv → +15.17 分`（约等于该局面增加 `10.26 PT` 的分值）。换种子后平均费率为 `1.6630–1.6933 分/PT`、`+3 Hint Lv` 为 `11.70–15.17 分`。这些是实验模型输出，不是真机终局系数。

## 真机标签与采用门槛

`--labels` 读去标识的 JSON 数组，每行 `{run, deck, h, p, nextH, ptDelta, score, hitScore, ptScore}`。`run` 唯一，至少三个 `deck`；`score` 为同一技能池、五维、适性、已学技能和切者状态下可用 `p` 换来的额外白技分，`hitScore` 只改变 Hint，`ptScore` 只增加 `ptDelta`。先使用无切者组；单份购买前 `finalScore` 不是结算标签。普通 Hint 不增加金技获取。实验里的样本池、预算、平均提升与实际对局分布不同，不能据此改默认值。

进入决策比较时，固定基策、搜索预算及 `pt_favor_rate`，同一批终局样本分别重算、成对用同种子比较；对每个 rollout 单独计算非线性终局分再取均值。用独立评分标签对比动作损失与终局收益，至少主卡组和留出卡组同向，成对 95% CI 不跨零再考虑换默认。
