# 基线（变更探测器）

一档一个 JSON，记录**固定局面条件 + 固定种子块**下的均分。判定只比分数与 PT 的均值，
不比耗时（耗时随机器负载漂移）。`README.md` 不是基线，判定时跳过。

录制口径（2026-11-13 起）：`data/constants.json` 的 `pt_score_rate = 1.88`、默认档
`pt_favor_rate = 1.931954`；改其中任一项都要重录（评分 PT 项 = `total_pt × pt_score_rate`）。

## 档位

| 文件 | 局面条件 |
|---|---|
| `a-normal.json` | 普通马娘 105902，无局外 buff（`qie=none`、`shield=0`，= 仓内默认档） |
| `b-ideal.json` | 狄杜斯 106302，小切 + 心情盾 2（`qie=xiaoqie`、`shield=2`） |

2026-11-11 起两档卡组随默认档换卡：1 耐构成 `30300` → `30324`（耐·莫名其妙），
2 耐档为 `30300 + 30324`；`[sim].cards` 与 `benchmark/decks/*` 主行已同步，影子 / panel 夹具不动。

每条记录按训练员与 `search_n` 分开：手写档 100 局（每局约 0.3 ms），搜索档当前 10 局
（N=8192，单局约 20 s）。搜索档补满 100 局后把 `games` 与均值一并更新。

## 复跑

```bash
# 全部档、两种训练员
./target/release/bench baseline

# 只跑理想档的手写项
./target/release/bench baseline --name b-ideal --trainer hand

# 缩短局数（判定容差会按合并标准误自动放宽）
./target/release/bench baseline --games 20
```

判定规则：`|Δ| ≤ max(3 × 合并标准误, 1% × 基线均值)` 视为通过，任一档不通过即非零退出。
容差可用 `--sigma`（默认 3）与 `--rel`（默认 0.01）调整。

输出表带 `score_sd` / `pt_sd` 列（样本标准差，n−1 口径，与 JSON 一致）。重录 = 按表内
`*_mean` / `*_sd` 手动更新对应 JSON 记录（`--update` 待 S9 落地前的过渡做法）。

## 更新纪律

口径变更或数值修正后重录，并在 `docs/changelog.md` 的决定记录写明位移原因与影响面。
不要为了让门禁变绿而调容差。最近一次重录：2026-11-14（`extra_count` 五维由 [10,10,120,140,0]
下调为 [0,0,90,90,0]，技能点不变；四项 −342.1 ~ −1006.0，位移是开局属性直接少 100 点的确定性查表位移，
PT 均值 −153.3 ~ +60.1 基本不动）。
上一轮：2026-11-13（`pt_score_rate` 2.0 → 1.88；四项 −1381.9 ~ −1623.8，位移 ≈ −0.12 × PT 的评分公式直接换算）。
上一轮：2026-11-11（1 耐位 `30300` → `30324`；A/B 手写 +466.8 / +496.8、搜索 +379.6 / +155.7，
PT +53 / +48 / +106 / +141）；再上一轮：2026-11-09（守门 ④ 不屈例外 + 演目锁位 CRN 补消费；
分布随机序列位移，A/B 手写 +369±298 / 搜索 −196±425）。
